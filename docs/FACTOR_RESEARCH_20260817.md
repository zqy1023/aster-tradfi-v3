## 六、补充发现（同日续）

### 日历效应：统计显著但无经济意义
- 周内效应：周二/周五 t 值 3.5-3.7（0.2%/日），扣永续成本（0.21%/往返）后归零（周五净 +0.03%）
- 月末/月初：t 2.7-2.8 但幅度 0.2-0.3%，扣成本无效
- 隔夜 vs 日内：分标的差异大（NVDA/MSTR/AMD 隔夜强, AAPL/COIN 日内强），非普适因子

### 横截面动量：唯一有效 alpha ✅（重大发现）
- 方法：每月末按过去 N 月收益排序，做多 Top3-5，下月持有
- 12月动量 Top3 月调：**年化 73.2%、Sharpe 1.42**、分年度 [2022:-18%, 2023:+95%, 2024:+138%, 2025:+27%, 2026:+19%]
- 稳健性：Top5 Sharpe 1.45 / 排除NVDA Sharpe 1.11 / 季调 1.35 / 半年调 1.32 / 9月动量 1.28 —— 全部 60-82% 年化
- 多空组合 ≈ 0 → 不是"选股 alpha 净效应"，是强势股集中持有的 beta+动量增强
- 学术支撑：Jegadeesh-Titman(1993) 动量，最稳健的横截面因子之一
- 风险：12 标的小池 + 高度相关（科技/AI），集中度高；熊市年（2022）回撤大

### 更新后的完整结论
1. 方向因子（技术指标）：无效
2. 波动率因子（ATR%/Bandwidth）：有效，作风控层（VolTarget Sharpe 0.414→0.559）
3. **动量因子（12月横截面）：有效，作选股层（Sharpe 1.42）**
4. 建议系统方向：动量选股（月度 Top3-5）+ 波动率仓位管理（ATR% 动态调仓）+ 现有策略降级为信号参考
